# AI Rules: Соглашения по коду CSS

- Соответствовать stylelint.config.js.
- Используем CSS Modules.
- Стили находятся рядом с компонентом. См. структуру папок в **AGENTS.md**.
- Компонент может импортить только свои стили. Нельзя импортить стили из другого компонента.
- Все reset-ы стандартных стилей браузера, глобальные стили и переменные находятся только в `src/index.css`.
- Не дублируем значение цветов и размеров, если они есть в переменных. Используем переменные из `src/index.css`. Например `border: 2px solid var(--color-primary);`.
- Селекторы пишутся в kebab-case.
- Используем только серекторы по классам.
- Не используем селктор `*`. Это плохо сказывается на производительности стилей на всём проекте. В селекторе `.test > *` браузер найдёт сначала все элементы, потом отфильтрует только то, что лежит внутри `.test`. Это очень плохо.
- Никогда не делаем `transition: all`. Прописываем только нужные свойства.
- Используем вложенность:
```css
.button {
    border: 2px solid var(--color-secondary-dark);
    background-color: transparent;
    cursor: pointer;
    transition: border-color .2s, background-color .2s;

    &:disabled {
        cursor: not-allowed;
    }

    &.active {
        border-color: var(--color-primary);
        background-color: var(--color-primary-light);
    }
}
```

## Open-Closed Principle (OCP)

У родительского компонента есть 2 основных способа повлиять на стили дочернего компонента:
1. прокинуть через props данные, которые повлияют на отображение,
2. props.className.

**props.className** передаётся в большинство компонентов. Так родительский компонент может управлять позицией дочернего компонента. Самый частый пример, это задать margin.

Родительский компонент:
```tsx
export default function ShowListPage() {
    return (
        <div>
            <ShowsFilter className={ styles.filter } />
            <ul>
                ...
            </ul>
        </div>
    );
}
```
`+`
```css
    .filter {
        margin-bottom: 20px;
    }
```

Стили внутри компонента отражают внешний вид компонента. Они закрыты для излишней модификации.
А стили `props.className` указывают расположение дочернего компонента относительно родителя или братьев. Они открыты для расширения.

Не передаём `props.className` только в те компоненты, которые сами ответственны за своё расположение на странице.
Это компоненты самих страниц, модальные окна, всплывающие подсказки, нотификации и т. д.
